# v1's review records

These 25 files were written by HourKeep v1's review sessions between 2026-09-02 and 2026-10-15. v1's `.gitignore`
excluded the folders they were written to (`.agents/`, `semantic-review/` and `docs/hr1-readiness/reviews/`), so none
of them was committed while v1 was live. They were added here on 2026-10-16, after v1 was set aside, keeping the
folders they came from:

- `reports/`: the 2026-10-15 status report and the four validation reports that checked it
- `reviews/w8a/` and `hr1-readiness-reviews/`: reviewer reports from waves W6a, W7a and W8a
- `reviews/semantic-review-multi-model/`: three two-model review runs from 2026-10-15
- `semantic-review/`: one review from 2026-09-02

Each was written by an AI reviewer, so each is a record of what was checked at the time rather than a finding to rely
on now. Decision record 0001 on `main` cites the status report and its validation.
