# House-style mechanics and decisions

A house style is a set of decisions made for a specific readership. Prosekeep supplies a worksheet and checks; the owner defines the actual values. Do not impose Vloora's or GSA's mechanics on a different writer by default.

| Topic | Questions to settle | Possible rule |
| --- | --- | --- |
| Case | What capitalization applies to pages, labels, buttons and headings? | Sentence case for most UI and headings; named entities retain exact capitalization |
| Voice | When is first person, second person or the passive appropriate? | Address readers directly for tasks; keep first-person essays personal; name the actor |
| Acronyms | Which are obvious to this audience? | Expand unfamiliar terms on first use; preserve familiar API and AI |
| Lists | Are items fragments or full sentences? | Capitalize consistently; periods on full sentences only; use numbered lists for true sequences |
| Numbers | Where should small numbers be spelled out? | One through nine in prose, with explicit exceptions for tables, units, figures and labels |
| Percentages | Word or symbol in narrative? | Vloora: '40 percent' in running copy; GSA: generally '40%' |
| Dates | Month-first, day-first, ISO, or localized? | Display month-first prose dates when selected; ISO 8601 in metadata |
| Ranges and dashes | Are prose dashes acceptable? | Vloora avoids prose em/en dashes while permitting an en dash for numeric ranges |
| Colons | What capitalization follows? | Use a capital letter after a colon only for a complete following sentence, if project policy says so |
| Names | First and later mentions? | Full name first; subsequent reference follows newsroom or local policy |
| Abbreviations | Preferred spelling, symbols and casing? | email, website, login (noun), log in (verb); document local exceptions |
| Citations | Where do sources go and how are they numbered? | Primary-source links and dates; numbered notes for formal papers if that is the document model |
| Links | What text and external-link markers are appropriate? | Descriptive destination text; use an external marker only for actual external links if the site's design uses it |
| Captions and alt text | How are findings and media represented? | Say what the data or image shows; use a caption when it helps interpret evidence |
| Tables | When is a table appropriate? | Comparable cells, clear column labels, caption and proper semantic structure |
| Accessibility | Which tests and approvers are required? | Meaningful headings/labels, links, assistive-tech and keyboard checks; actual verification required |

## Adopting standards

The 18F and federal plain-language references favor active, conversational writing and content centered on reader tasks. GSA written style includes detailed page-mechanics decisions, including conventions that sometimes differ from Vloora. Select the governing guide and record exceptions in the project's `EDITORIAL.md`; a source-linked reference is not automatically a lint rule.

## Content decisions the software cannot infer

- Whether a repeated term is necessary precision or unwanted jargon.
- Whether an opinion is deliberate and part of the author's voice.
- Whether an apparent contradiction corrects an actual misconception.
- Whether to retain an em dash in an author's essay.
- Whether a citation adequately supports a specific factual claim.

Reviewer output should show the changed passage and why a chosen local rule applies. It must identify deviations requiring the author's decision.
