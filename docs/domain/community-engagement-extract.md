# Medicaid community engagement: the rule extract

This file holds the rules for Medicaid community engagement, the work requirement in Public Law 119-21 and the interim
final rule at 42 CFR 435.550 to 435.563, one row per rule, each with its citation, its stored source and the words the
source uses. It is the authority for community engagement in this repository: where an older analysis file or the
skill disagrees with a row, the row wins, and where a row disagrees with its stored source, the source wins.
Rows arrive a topic at a time, so a topic without a heading here has not been written yet.
Every check recorded here so far was made by an AI agent. No person has checked a row yet.
A row says what a rule is and where it comes from. Whether a requirement applies to a particular person, or whether
that person met it, is the agency's decision, and nothing here decides it.

### no-noncompliance-notice-when-other-factors-unanswered

  renewal form has elapsed. A State does not need to send the noncompliance notice where it must request
