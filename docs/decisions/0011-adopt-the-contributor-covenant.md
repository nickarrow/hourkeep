# 0011. Adopt the Contributor Covenant 3.0 as HourKeep's code of conduct

Date: 2026-10-26

Status: Accepted on 2026-10-26, decided by the owner

## Context

Decision record 0008, accepted on 2026-10-26, says under Consequences: "There is no code of conduct yet. One comes when
a second person starts contributing regularly, or before the owner invites policy experts to comment on the review
pages, whichever is first." The owner had already invited them, in a post on LinkedIn, so the second of those had
happened before 0008 was accepted. Comments on HourKeep's wording come through GitHub issues, a Google Form and
policy@hourkeep.app (decision records 0005 and 0008), and pull requests from outside have begun.

## Decision

`CODE_OF_CONDUCT.md`, at the repository root, holds the
[Contributor Covenant 3.0](https://www.contributor-covenant.org/version/3/0/), as published, apart from two places:

- The means of reporting, which the Covenant leaves for each project to write, is an email to conduct@hourkeep.app. It
  reaches the owner, who acts as the Covenant's Community Moderator. A report about the owner himself, for anything on
  GitHub, can go to GitHub instead, and the paragraph links GitHub's guide to reporting abuse.
- The Covenant's note before its enforcement ladder, which tells a project to edit the ladder if it has its own
  process, is removed. HourKeep has no other process, so the ladder stands as written.

HourKeep's community spaces include the repository's issues and pull requests, and the forms and email through which
people comment on HourKeep's wording. The Covenant also covers anyone officially representing HourKeep.

The file keeps the Covenant's own license, CC BY-SA 4.0, and `README.md` says so beside the GPL. `CONTRIBUTING.md` and
`README.md` link it, and `CONTRIBUTING.md` lists it among the files the owner decides.

This record supersedes the two sentences of 0008 quoted above. The rest of 0008 stands.

## Consequences

0008's status names this record.

A report reaches one person. Until there is a second maintainer, a report about the owner has nobody else in the
project to go to: GitHub takes one about anything on GitHub, and nothing takes one about the forms or the email.

The file is a document, not code HourKeep runs, and its attribution section stays as published. A change to it comes in
under CC BY-SA 4.0, as `CONTRIBUTING.md` says.

GitHub's community profile for the repository lists the file.

The review pages do not link it yet. They are generated by `scripts/build-review-pages.py`, so a link there means a
change to the generator and its tests, made on its own.

## Alternatives considered

Contributor Covenant 2.1. 3.0 is the current version, and its rule against failing to credit sources, which 2.1 does
not have, fits a project built on citations.

A short code written for HourKeep. A text people already recognise carries more weight than a new one, and it costs
nothing to adopt.

Reports to policy@hourkeep.app. They would arrive in the queue of comments on HourKeep's wording, which the owner
screens for a different purpose.

Licensing the file under GPL-3.0-or-later with the rest of HourKeep. Creative Commons lists only version 3 of the GPL as
compatible with BY-SA 4.0, so an adaptation cannot take "version 3 or later"
([FSF license list](https://www.gnu.org/licenses/license-list.en.html#ccbysa), read 2026-10-26).
